# 额度口袋的密码登录页

这是额度口袋的可选登录服务，让手机看到普通密码表单。完整的安装步骤和与已有 Nginx 配合的示例在[主 README](../README.md#部署给手机和电脑使用已有-nginx)。

服务只监听服务器本机。它读取一个专门创建的 Apache MD5（`$apr1$`）格式 htpasswd 文件，验证密码后发放 `Secure`、`HttpOnly`、`SameSite=Strict` 的会话 Cookie；不要求输入用户名。会话仅在内存中保存，30 天后或服务重启后需要重新登录。15 分钟内同一来源输错 8 次会暂时限制尝试。

请使用 HTTPS，并把页面与查询接口都放在同一访问保护下。不要把 18741 或 18743 直接对公网开放。服务本身不会修改密码文件，也不会把明文密码存盘或打印日志。
