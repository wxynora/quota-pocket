怎么获取令牌？
在站点点头像 → 安全与访问 → 创建访问令牌，把带「查看」的权限都勾选，再复制令牌。用户 ID 可在站点个人资料中查找；它不是调用模型的 API Key。部分站点没有权限选项，直接复制系统访问令牌即可。

充值比例小计算

填入两个数字，自动计算下方的比例。

例如花 ¥50 充值得到 100 站内额度，填 0.5；不填默认按 1:1 换算。

令牌保存在此设备的浏览器数据中；导出配置不包含令牌。

PRICE COMPARISON

模型比价

按充值兑换比例折算人民币，未填写时按 1:1 计算；按量与按次分别从低到高排序。每次打开时读取站方近 1 小时成功率，不是实时试调，分组和密钥权限可能不同。

LOCAL LOCK

本机加密

至少 8 位，建议使用较长且独立的密码。页面重新加载后需要解锁；忘记密码无法恢复加密配置。

保护保存在此设备的站点配置和令牌；余额离线快照未加密。查询时令牌仍会经过你选择的查询服务。

LOCAL LOCK

输入此设备设置的解锁密码，继续使用额度口袋。

忘记密码无法恢复加密数据；可清除本设备的额度口袋配置后重新连接站点。
