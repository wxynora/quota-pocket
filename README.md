# 额度口袋 · Quota Pocket

一个给 New API 站点用的小账本。网页可以安装为 PWA，界面和配置保存在使用者自己的设备上；刷新余额和价格时才需要联网访问站点。

- 汇总各站剩余额度、累计使用、今日和本月用量；可分别或一键刷新。
- 添加多个站点或同站多个账号，搜索、筛选，并可为每个站点设置低余额提醒。
- 查看调用日志、模型及分组价格，或跳转到站点充值页。
- 搜索模型跨站比价，按量和按次分开排序；按量可选按输入或输出价格排序。
- 按站点填写充值兑换比例，统一折算为人民币比价。暂不能确认的价格会列在未排序区域。
- 离线打开界面并查看上次成功刷新后的余额。站点配置可导入、导出；导出不含令牌和转发口令。

## 开始使用

将 `public/` 中的静态文件托管在 HTTPS 地址，首次联网打开后可安装为 PWA。电脑端使用浏览器的安装按钮；Android 可在浏览器菜单选择安装或添加到主屏幕；iPhone 可在 Safari 的分享菜单选择“添加到主屏幕”。离线时显示的余额是上次记录，联网刷新后才是最新值。

开发时可以在这个目录启动仅供本机预览的静态服务：

```sh
python3 -m http.server 8080 --bind 127.0.0.1 --directory public
```

然后打开 `http://127.0.0.1:8080/`。直接双击文件不支持 PWA 安装；手机使用需要 HTTPS 托管地址。PWA 源码是静态文件，默认不包含任何托管后端。

## 连接站点

1. 在站点的个人设置中找到 **用户 ID** 和 **系统访问令牌**，填入站点设置。这个令牌用于管理接口，不是调用模型用的 API Key。
2. 可选地设置低余额提醒阈值。阈值按站点自身显示的单位填写。
3. 比价时，填写“每 1 站内显示单位实际花费多少人民币”。例如 ¥50 换到 100 站内单位，就填写 `0.5`。不填的站点仍会显示，但不会混入人民币排名。
4. 充值按钮根据站点返回的前端主题选择 `/wallet` 或 `/console/topup`；如果站点使用自定义页面，可以手动填写地址。此按钮只打开页面，不会替你付款。

今日和本月用量来自站点的消费日志统计，按当前设备的本地时间计算；日志保留和访问权限由站点决定。模型列表和分组来自站点公开或账号可见的报价数据，不能保证某个密钥的实际权限或渠道实时可用性。

## 跨域与可选转发

PWA 受浏览器跨域规则限制。**有些 New API 站点没有对其他网页开放查询接口**；仅安装 PWA 不能绕过这个限制。如果站点允许，网页直接查询；否则需要站点方开放 CORS，或自行部署本项目的可选只读转发组件。

`proxy/worker.mjs` 是可自行部署的 Cloudflare Worker 示例。它只接受配置过的 PWA 来源和站点来源，只转发查询余额、日志、报价与状态所需的 GET 接口，并要求转发口令；不会跟随站点重定向。添加新站点时，也要把其 HTTPS 来源加入允许列表。

自行部署的基本步骤：

1. 修改 `proxy/wrangler.toml` 的 `ALLOWED_APP_ORIGIN`（PWA 的精确来源，不含路径）和 `ALLOWED_SITE_ORIGINS`（逗号分隔的站点 HTTPS 来源）。
2. 在 `proxy/` 中使用 Cloudflare Wrangler 登录自己的账号，将 `PROXY_KEY` 设置为 secret，再部署 Worker：

   ```sh
   npx wrangler secret put PROXY_KEY
   npx wrangler deploy
   ```

3. 在额度口袋的“设置”里填写 Worker 地址和刚才设置的口令。

项目不提供默认公共转发服务。启用转发时，站点访问令牌会经过你填写的服务；本示例代码不保存或打印令牌，但服务运营方及其平台有能力接触经过的数据。请只使用自己控制或信任的服务。

## 隐私和数据

站点令牌、转发口令、站点配置和上次余额保存在本机浏览器存储中，**未加密**。浏览器清理站点数据、切换浏览器或设备，可能导致本地数据丢失；不含令牌的配置可以事先导出。调用日志按需读取，不会保存到离线快照中。

访问令牌可能拥有账号管理权限，请妥善保管。网页托管者能够更新网页代码，因此对敏感账号建议自行托管、检查源码，并仅使用可信的转发服务。

## 价格口径

普通倍率计费按站点给出的模型倍率、输出倍率、分组倍率、额度单位和显示汇率换算；按次价格按站点给出的每次价格和分组倍率换算。对于 New API 简单的单层 `tier(...)` 文本计费表达式，识别输入／输出系数或固定每次价格。

复杂条件、阶梯、未提供倍率、特殊计费等情况不推算成单一价格。比较仅展示普通文本输入／输出或每次价格；缓存、图像、音频、请求条件和其他附加费用以站点实际规则为准。不同站点显示单位并不天然等价，人民币排名依赖使用者填写的实际充值兑换比例。

## 开发与验证

需要 Node.js 20 或更新版本，运行 `npm test` 可检查价格换算和转发边界。代码不附带真实站点凭据，也不要求连接实际账号运行测试。
